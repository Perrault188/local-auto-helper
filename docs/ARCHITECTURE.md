# Architecture

## 请求路径

```text
浏览器
  ↓
本地HTTP服务
  ↓
受约束的创建与管理服务
  ↓
工作流执行器
  ↓
Mock消息和文件适配器
  ↓
本地SQLite与演示文件
```

## 设计边界

`prototype`负责界面和本地交互。`demo/server.mjs`提供静态文件与JSON接口。`engine`保存领域对象、校验规则、执行器、调度器和仓库。`contracts`定义输入输出结构。`fixtures`只保存合成示例和评估集。

意图识别只决定候选领域和能力。可执行动作必须来自本地注册表，参数必须通过确定性校验，副作用必须经过执行器和Mock适配器。

## 存储

默认使用Node.js内置SQLite。运行数据位于被Git忽略的本地目录。公开仓库不附带运行数据库。

## 网络

默认没有外部网络调用。只有配置远程意图提供方后，意图分类请求才会访问允许列表中的HTTPS端点。HTTP演示服务只监听`127.0.0.1`。
